Problema

Fechamento no escuro. Só vemos o mínimo garantido. Excedente, isenções e reajustes são planilha paralela — lento e sem trilha.

Solução

Um cockpit por mês de referência. Uso real da DONC API + contrato + exceções. MRR real, excedente e relatórios fechados com CNPJ/SaaS_ID.

Investimento

Reuso do Cockpit de Profissionais. Mesma UX, 3 RPCs, nova tabela de exceções. Flag própria com kill-switch. Sem ERP novo.

E os módulos? É uma pizza fatiada, não duas pizzas.

Se a licença custa R$ 59,90, a soma dos módulos deve fechar em R$ 59,90. É só o rateio para saber quanto cada produto gera — não soma ao valor base. Ex: Core R$ 35,00 (58%) + Chat R$ 24,90 (42%) = R$ 59,90. O sistema hoje soma errado e será corrigido.

Exceções e correção — controle e risco

1. Exceções são negociações com prazo

Toda exceção tem de ___ até ___ + motivo + quem criou. Fora da vigência, volta ao preço cheio sozinho.

TipoEfeitoQuando usar
IsençãoMRR = 0carência
Desconto %MRR × (1−%)ex: 20% 3 meses
Valor ↓troca preçoex: 59,90→49
Piso 0remove pisopaga só uso
JanIsençãoMarAbr normal

2. Trilha auditável

Toda criação grava quem + quando + por quê. Sem isso, auditoria reprova.

Criado porfinance@donc · 12/08/2026
MotivoNegociação comercial #8421
Vigência01/01/2026 → 31/03/2026
Acesso escrita: admin, finance e sales · manager só leitura · Validado Q4a

3. Correção com toggle

Fase 1: Finance informa IPCA 4,62%, sistema recalcula e mostra badge. Um botão decide se entra naquela fatura.

Aplicar nesta cobrança
ON → R$ 62,67 · OFF → R$ 59,90
Fase 2 será automática no mês de renovação.

Risco sem isso: sem correção = perda por inflação; com correção indevida = atrito comercial.
